# HX 图片工具箱

一个**零依赖、纯前端**的本地图片处理工具。所有处理均在浏览器本地完成，图片不会上传到任何服务器。

## 使用方法

直接双击 `index.html` 用现代浏览器（推荐 Chrome / Edge）打开即可。

也可以启动本地服务访问：

```bash
# 任选其一
python -m http.server 8080
npx serve .
# 然后访问 http://localhost:8080
```

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 压缩 | 质量滑块（5-100）、实时预估输出大小、**压缩到目标大小**（自动二分搜索最合适的质量值） |
| 格式导出 | JPEG / WebP / PNG 互转，JPEG 可设置底色填充透明区域，可自定义文件名后缀 |
| 裁剪 | 交互式裁剪框（8 个控制点 + 拖拽移动/框选），支持 1:1 / 4:3 / 16:9 等比例锁定 |
| 缩放 | 按百分比或自定义宽高（可锁定/解锁宽高比，支持非等比拉伸） |
| 旋转 | 左右 90° 旋转、水平/垂直翻转、-45°~45° 微调角度（自动扩展画布） |
| 亮度 / 对比度 | 0-200 实时调节 |
| 锐化 | 3×3 卷积锐化，0-100 强度可调 |
| 水印 | 文字水印：字体/颜色/加粗、字号、不透明度、旋转、九宫格定位、边距、全图平铺 |
| 批量 | 多选/拖拽/粘贴添加图片，每张独立保存编辑状态，一键导出全部 |

## 界面布局

- **左侧**：图片队列（每张图独立记录编辑设置）
- **中间**：预览区（棋盘格表示透明区域；底部状态栏显示原始/输出尺寸与大小）
- **右侧**：功能面板（旋转翻转 / 裁剪 / 缩放 / 亮度对比度锐化 / 水印 / 导出与压缩）

## 处理管线

固定顺序，保证所见即所得：

```
原图 → 旋转/翻转/微调角度 → 裁剪 → 缩放 → 亮度 → 对比度 → 锐化 → 水印 → 编码导出
```

- 预览按最长边 1400px 渲染，导出时才以全分辨率 + 设定尺寸重新处理，保证编辑流畅。
- 修改旋转/翻转会使裁剪坐标失效，裁剪会被自动清除（面板中有提示）。
- `ctx.filter` 不可用的旧浏览器会自动回退到像素级亮度/对比度实现。

## 说明

- GIF 只取第一帧；导出 WebP 在不支持的浏览器会自动回退为 PNG。
- “压缩到目标大小”仅适用于 JPEG / WebP（PNG 为无损格式），若最低质量仍超出目标，会提示先缩小尺寸。
